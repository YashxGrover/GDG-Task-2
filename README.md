# Python Beginner Challenge & Student Management System

## Project Overview
This repository contains my solutions for **Part 1 (Python Fundamentals)** and **Part 2 (Student Management System)** of the Python Beginner Challenge. The Student Management System is a menu-driven command-line application that lets users add student records, view all saved students, search by roll number, and calculate average marks with persistent file storage.


## How to Run the Project

1. Ensure **Python 3** is installed on your computer.
2. Open a terminal and clone this repository:
   ```bash
   git clone [https://github.com/YashxGrover/GDG-Task-2.git](https://github.com/YashxGrover/GDG-Task-2.git)
   ```
3. Navigate into the `Part 2` folder:
   ```bash
   cd "GDG-Task-2/Part 2"
   ```
4. Run the program:
   ```bash
   python3 Student_Management_System.py

 Student_Management_System.py
   ```
5. Once running, enter a number from `1` to `5` to perform an action:

   1. **Add student** – Enter roll number, name, and marks to save a new record.
   2. **View all students** – Display all saved student records.
   3. **Search student by roll number** – Look up a specific student's details.
   4. **Calculate average marks** – Compute the average score for a student.
   5. **Exit** – Close the program safely.
